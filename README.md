## 🚀 Top Solid Waste Routing Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Waste Collection Route Optimization, Fleet Dispatch, Service Verification & Municipal/Commercial Hauling*  

This repository tracks notable **SaaS platforms** and **open-source projects** for **Solid Waste Routing**. These tools optimize collection routes, manage dispatch and fleet operations, capture proof-of-service, handle missed pickups and exceptions, support residential/commercial/recycling streams, and improve efficiency for municipalities and private haulers.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## 💻 Open-Source GitHub Projects

- **[Google OR-Tools](https://github.com/google/or-tools)** [![Stars](https://img.shields.io/github/stars/google/or-tools?style=social&color=white)](https://github.com/google/or-tools/stargazers)  
  Powerful open-source optimization suite including vehicle routing, constraint programming, and solvers frequently applied to waste collection VRP variants.

- **[OSRM (Open Source Routing Machine)](https://github.com/Project-OSRM/osrm-backend)** [![Stars](https://img.shields.io/github/stars/Project-OSRM/osrm-backend?style=social&color=white)](https://github.com/Project-OSRM/osrm-backend/stargazers)  
  High-performance open-source routing engine built on OpenStreetMap data, widely used as the foundation for custom vehicle routing and matrix calculations.

- **[GraphHopper](https://github.com/graphhopper/graphhopper)** [![Stars](https://img.shields.io/github/stars/graphhopper/graphhopper?style=social&color=white)](https://github.com/graphhopper/graphhopper/stargazers)  
  Fast open-source routing engine with Java and other bindings, supporting custom profiles and matrix calculations for logistics applications.

- **[Valhalla](https://github.com/valhalla/valhalla)** [![Stars](https://img.shields.io/github/stars/valhalla/valhalla?style=social&color=white)](https://github.com/valhalla/valhalla/stargazers)  
  Open Source Routing Engine for OpenStreetMap data, offering flexible routing algorithms suitable for dynamic VRP matrices.

- **[OpenRouteService](https://github.com/GIScience/openrouteservice)** [![Stars](https://img.shields.io/github/stars/GIScience/openrouteservice?style=social&color=white)](https://github.com/GIScience/openrouteservice/stargazers)  
  Open-source routing service based on OpenStreetMap offering directions, isochrones, matrices, and optimization APIs suitable for fleet planning.

- **[VROOM](https://github.com/VROOM-Project/vroom)** [![Stars](https://img.shields.io/github/stars/VROOM-Project/vroom?style=social&color=white)](https://github.com/VROOM-Project/vroom/stargazers)  
  Open-source Vehicle Routing Problem solver that integrates with OSRM/OpenRouteService for capacitated, time-window, and multi-vehicle optimization.

- **[pgRouting](https://github.com/pgRouting/pgrouting)** [![Stars](https://img.shields.io/github/stars/pgRouting/pgrouting?style=social&color=white)](https://github.com/pgRouting/pgrouting/stargazers)  
  Open-source extension for PostGIS/PostgreSQL that provides routing and network analysis functions useful for geospatial waste route planning.

- **[RoutingPy](https://github.com/GIScience/routingpy)** [![Stars](https://img.shields.io/github/stars/GIScience/routingpy?style=social&color=white)](https://github.com/GIScience/routingpy/stargazers)  
  A Python library to access multiple public/private routing web services (OSRM, ORS, GraphHopper, Valhalla, etc.) in a unified way.

- **[PyVRP](https://github.com/PyVRP/PyVRP)** [![Stars](https://img.shields.io/github/stars/PyVRP/PyVRP?style=social&color=white)](https://github.com/PyVRP/PyVRP/stargazers)  
  High-quality open-source Python VRP solver focused on performance and research-grade vehicle routing problems, including waste-style instances.

- **[VeRoViz](https://github.com/VeRoViz/veroviz)** [![Stars](https://img.shields.io/github/stars/VeRoViz/veroviz?style=social&color=white)](https://github.com/VeRoViz/veroviz/stargazers)  
  Vehicle Routing Observation and Visualization tool to generate, analyze, and view VRP datasets.

- **[Urban-Waste-Collection](https://github.com/N-Wouda/Urban-Waste-Collection)** [![Stars](https://img.shields.io/github/stars/N-Wouda/Urban-Waste-Collection?style=social&color=white)](https://github.com/N-Wouda/Urban-Waste-Collection/stargazers)  
  Research codebase for integrated container selection and routing policies in urban solid waste collection, with simulation and OSRM support.

- **[docker-ors-vroom](https://github.com/stefanocudini/docker-ors-vroom)** [![Stars](https://img.shields.io/github/stars/stefanocudini/docker-ors-vroom?style=social&color=white)](https://github.com/stefanocudini/docker-ors-vroom/stargazers)  
  Ready-to-run Docker setup combining OpenRouteService and VROOM for testing and deploying vehicle routing solutions.

- **[VRP Trash Collection projects](https://github.com/cvvergara/vrp-trash-collection)** [![Stars](https://img.shields.io/github/stars/cvvergara/vrp-trash-collection?style=social&color=white)](https://github.com/cvvergara/vrp-trash-collection/stargazers)  
  Implementations of capacitated multi-trip time-window VRPs specifically modeled for garbage collection (depot → containers → dump cycles).

- **[Multi-Vehicle-Routing](https://github.com/ai4smlab/Multi-Vehicle-Routing)** [![Stars](https://img.shields.io/github/stars/ai4smlab/Multi-Vehicle-Routing?style=social&color=white)](https://github.com/ai4smlab/Multi-Vehicle-Routing/stargazers)  
  Full-stack open playground for VRP with OR-Tools, Pyomo, VROOM solvers, map frontend, and distance-matrix adapters.

- **[Refuse-Collection-Vehicle-Route-Optimization](https://github.com/fabmid/Refuse-Collection-Vehicle-Route-Optimization)** [![Stars](https://img.shields.io/github/stars/fabmid/Refuse-Collection-Vehicle-Route-Optimization?style=social&color=white)](https://github.com/fabmid/Refuse-Collection-Vehicle-Route-Optimization/stargazers)  
  Tool leveraging OSRM and VROOM to optimize refuse collection vehicle routes from address data and analyze distances.

### 🛠️ Frameworks for custom systems
Combine **OSRM or OpenRouteService** for road networks and matrices, **VROOM / OR-Tools / PyVRP** for optimization, a simple dispatch UI or GIS layer, and optional IoT fill-level inputs to create a complete open-source solid waste routing platform.
